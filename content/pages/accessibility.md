# Accessibility

BetterSiquijor aims to make public information usable on mobile devices, with a keyboard, and with assistive technology.

## Using this website

- Use the **Skip to content** link when navigating with a keyboard.
- Use Tab and Shift+Tab to move between links and controls.
- On smaller screens, use the **Open main menu** button to reveal navigation.
- Use your browser's zoom controls to enlarge the text.
- Search includes service pages, government information, and source notes.
- Reduced-motion preferences are respected.

Linked agency websites and PDF files may have different accessibility limitations. We have not independently certified this website against WCAG.

If a page is difficult to use, [report the accessibility problem on GitHub](https://github.com/BetterSiquijor/BetterSiquijor/issues/new). Include the affected page and how the issue prevents you from accessing the information. Do not include private information.
